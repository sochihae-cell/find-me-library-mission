# 나를 찾아줘

### 책을 찾아라! 도서관 추격전

도서관 수업용 조별 미션·암호판·4단계 방탈출 웹앱입니다. 학년·과목·난이도 30개 조합을 모두 채운 기본 문제 60개와 원본 보호 방탈출 20개가 포함되어 있습니다. 자료는 브라우저 로컬 저장소에 저장되며 JSON으로 백업/가져오기 할 수 있습니다.

## 실행
Node.js 22 이상과 pnpm 설치 후 `pnpm install`, `pnpm dev`를 차례로 실행합니다.

## GitHub + Vercel 배포
이 폴더 전체를 새 GitHub 저장소에 올립니다. Vercel의 **Add New → Project**에서 저장소를 연결하고 Framework Preset **Next.js**, Build Command `pnpm build`로 배포합니다. 환경 변수, 데이터베이스, 유료 API 설정은 필요 없습니다.

## 주의
자료는 기기별 브라우저에 저장됩니다. 교사 메뉴의 **백업·가져오기**에서 수시로 백업 파일을 내려받으세요.
